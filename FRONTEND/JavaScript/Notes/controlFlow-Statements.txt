Loops:

    - loops are used to iterate certain statements until aspedific condition is false. 
      it execuetes the body when condition is true and keeps on executing until the condition is false. 
      one execution is called itration.
    -Loops are basically two types
            1. Entry Control loops
            2. Exit control loops

Entry Control Loops: It checks the condition before executing the body (at entry point).
                    Ex-While and for

Exit Control Loops: It checks the condition after execuetes the body (at exit point).
                    Ex- do While.

While Loop:

    -while loop is an entry control loop which contains initialization, condition, updation at three different points.
    
    Syntax:
            initialization;
            while(condition)
            {
                //----------
                updation;
            }

Q. Write a Js code to print the given name in reverse.

    let name=prompt("Enter any Name")

    let i=name.length-1;
    let rev="";
    while(i>=0)
    {
        rev=rev+name.charAt(i);
        i--;
    }
    alert(`Reverse of Name is ${rev}`);
