Picture links use an image as the clickable element. Clicking the image will take you to the specified URL.

Local Links

Local links are used to navigate to other HTML files or resources within the same project or server.

To demonstrate a local link, imagine you have another file named about.html in the same folder. Click here to go to the "About Us" page (this link will likely result in a "file not found" error unless such a file exists).

Email Links

Email links (mailto links) open the user's default email client, pre-filling the recipient's address.
