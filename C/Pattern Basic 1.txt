Pattern 21
Write the logic for the below program in c ?



                           1

                  4       9

       16     25     36   

49   64     81   100
Sample Input
5
Sample Output
                           1

                  4       9

       16     25     36 

49   64     81   100

Answer:

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n); // Number of rows
    int num = 1;

    for(int i = 1; i <= n; i++) {
        // Print spaces on the left
        for(int s = 1; s <= n - i; s++) {
            printf("  "); // 2 spaces for alignment
        }
        // Print numbers
        for(int j = 1; j <= i; j++) {
            printf("%d ", num);
            num++;
        }
        printf("\n"); // Move to next row
    }

    return 0;
}
